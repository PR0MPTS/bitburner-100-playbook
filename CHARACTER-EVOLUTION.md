# Portrait Asset Convention

Approved portraits belong in `assets/portraits/`. New portrait filenames must
begin with the two-digit chronological sequence and use this form where a run
number is known:

`NN-run-XX-milestone.png`

`NN` is the portrait sequence, and `XX` is the Bitburner run number. Continue
future entries with `06-`, `07-`, and so on. For portraits without a confirmed
run number, retain an appropriate session- or history-based description after
the sequence prefix, as with `01-session-01-humble-beginnings.png` and
`02-early-black-hand-operative.png`.

For example, the current canonical image is
`05-run-06-quadrillionaire.png`. Preserve the original file extension and
image appearance when adding approved artwork.

# Character Continuity Rules

- PR0MPTS evolves forward as the playthrough progresses.
- The latest approved portrait is the reference for future images. At present,
  that reference is **Run 6 — Quadrillionaire**.
- Earlier portraits are historical snapshots and must not be retroactively
  altered.
- Wealth, faction affiliations, technology, clothing, and augmentations must
  reflect actual game progress.
- Major visual transformations must be earned through gameplay.
- **White Suit Era → White Suit + Cybernetics → Full Transcendence** remains
  planned future progression, not an automatic unlock.
- Backwards progression is permitted only when explicitly requested by the
  user.
